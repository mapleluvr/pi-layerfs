## Deployment and remaining limits

- Linux x86-64 with the SDK/native/runtime identities in [pairing.json](../../integrations/layerfs/pairing.json).
- The Pi control process must have the SDK's control view and the exact mounted file view. Commands use LayerFS execution and its nonroot command identity.
- The same-version registry SDK is an older candidate. The source release requires a prepared paired SDK/runtime.
- Output arrives on completion. Live streaming and cross-stream ordering are unqualified.
- Native SDK/daemon unknown-fault injection, broader platform support, and crash/power-loss durability remain unqualified.
- File-path defenses have focused local and fixed-runtime coverage. Concurrent directory relocation, mount changes, and hard-link aliases remain outside the proven atomic boundary.
- The historical E2E preparation had an initial authentication-environment inheritance caveat. Subsequent helper processes used clean environments; authentication configuration and raw model records are excluded from publication.
- Project import/export, source write-back, machine bootstrap, and background-consumer publication are separate work.
