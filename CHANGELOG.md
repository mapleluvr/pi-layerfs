# Changelog

## 0.1.0 - 2026-11-22

Initial public GitHub source release under MIT.

- LayerFS-backed Pi read/edit/write tools, standalone Bash, and Workspace status.
- Versioned `pi-layerfs.execution` 1.2 hook for independent background-task consumers.
- Captured Workspace/execution identities, explicit unknown outcomes, bounded waits, exact cancellation, and original-output completion.
- Descriptor-pinned Linux filesystem operations and focused synthetic regressions.
- Public architecture, integration contract, fixed SDK/runtime pairing, and verification scope.

The release targets the qualified prepared Linux environment. LayerFS binaries and background consumers are distributed separately. Live streaming, broader platforms, native unknown-fault injection, and crash/power-loss persistence retain separate qualification requirements.
